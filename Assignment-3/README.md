# Assignment 3 - Greedy & Dynamic Programming

This folder contains the solutions for **Assignment 3** of the **EPAM Student Assignment 2026**.

## Topics Covered

- Greedy Algorithm
- Dynamic Programming
- Sorting
- Array-based Problem Solving

## Problems

### Problem 1 - Scholarship Distribution

A college wants to distribute scholarships to the maximum possible number of students without exceeding the available budget.

The scholarship requirements are sorted in increasing order, and scholarships are given to students requiring the smallest amounts first.

**Algorithm Used:** Greedy Algorithm

**Time Complexity:** O(N log N)

**Space Complexity:** O(1) excluding sorting space

---

### Problem 2 - Maximum Learning Points

A student wants to maximize learning points while avoiding selecting two consecutive topics.

Dynamic Programming is used to determine the maximum points that can be obtained.

**Algorithm Used:** Dynamic Programming

**Time Complexity:** O(N)

**Space Complexity:** O(N)
