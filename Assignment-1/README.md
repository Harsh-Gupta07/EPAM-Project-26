# Assignment 1 - JavaScript Case Study (XYZ Bank)

## Overview

This assignment is part of the **EPAM Student Assignment 2026**. The objective was to develop a simple banking web application using **HTML** and **JavaScript** based on the XYZ Bank case study.

## Problem Statement

Implement the XYZ Bank customer page with the following functionalities:

- Display a welcome message using JavaScript.
- Show instructions for obtaining a Diwali coupon.
- Hide the instructions when the **Register** button is clicked.
- Validate the Customer ID entered by the user.
- Generate a coupon code based on the Customer ID.

## Features Implemented

- ✅ Welcome alert on page load
- ✅ Customer registration functionality
- ✅ Hide/Show instructions
- ✅ Customer ID validation
- ✅ Coupon generation using JavaScript
- ✅ Simple and user-friendly interface

## Technologies Used

- HTML5
- JavaScript (ES6)
